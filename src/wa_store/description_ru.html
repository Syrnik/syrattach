Плагин позволяет приложить к каждому товару любое количество файлов с описаниями — инструкции, драйверы, прошивки, сертификаты, чертежи. Список файлов появится на карточке товара, а покупатель скачает нужный, не обращаясь в поддержку.

 Загрузка перетаскиванием

Перетащите файлы в карточку товара или выберите их в обычном диалоге. Прогресс-бар покажет ход загрузки.

 Один файл — много товаров

Общую для линейки инструкцию достаточно загрузить один раз и прикрепить к нужным товарам поиском по имени.

 Свой порядок файлов

Файлы в списке сортируются вручную перетаскиванием — покупатель увидит их именно в том порядке, который вы задали.

 Шаблон в теме дизайна

Вид списка файлов на витрине задаётся обычным файлом шаблона в папке темы — правки не потеряются при обновлении плагина.

Работа с файлами в бэкенде

Плагин добавляет в карточку товара раздел «Прикреплённые файлы». Он работает и в новом, и в устаревшем редакторе товара.

  • Загрузка любого количества файлов перетаскиванием или через диалог выбора
  • Прогресс-бар и добавление файла в список сразу после загрузки
  • Произвольное описание для каждого файла
  • Ручная сортировка файлов перетаскиванием
  • Кнопка «Прикрепить существующий файл» — поиск по имени среди уже загруженных файлов

Один и тот же файл, прикреплённый к нескольким товарам, хранится на диске в единственном экземпляре, но описание и позиция в списке у каждого товара свои.

Вывод списка файлов на витрине

Список файлов выводится на карточке товара в месте, предусмотренном темой дизайна для хука frontend_product.block или frontend_product.block_aux — какой именно использовать, выбирается в настройках плагина.

Чтобы изменить вёрстку списка файлов, положите файл plugin.syrattach.attachments.html в папку активной темы дизайна. Плагин найдёт и применит его автоматически, а при обновлении плагина ваш шаблон останется нетронутым. Если такого файла в теме нет, используется встроенный шаблон.

В шаблоне доступна переменная $attachments — массив данных о прикреплённых файлах:

$attachments = array(
    array(
        'id'          => $id,      /* ID вложения */
        'file_id'     => $file_id, /* ID файла */
        'name'        => $name,    /* имя файла */
        'ext'         => $ext,     /* расширение файла */
        'description' => $desc,    /* описание файла */
        'size'        => $size,    /* размер файла в байтах */
        'url'         => $url      /* ссылка на файл */
    ),
);

Встроенный хелпер

Если список файлов нужен не в месте хука, а в произвольной части шаблона товара, вызовите хелпер плагина. Он вернёт либо готовый HTML, либо массив с данными о файлах — чтобы вывести их полностью своей вёрсткой.

{* готовый HTML по шаблону плагина или темы дизайна *}
{$wa->shop->syrattachPlugin->render($product.id)}

{* массив файлов для собственной вёрстки *}
{$files = $wa->shop->syrattachPlugin->getList($product.id)}

Такой вызов безопасен: если плагин отключён или удалён, шаблон не сломается. Устаревший синтаксис вызова хелперов тоже поддерживается.

Загрузка файлов при импорте из CSV

При импорте товаров из CSV файлы можно прикреплять сразу, не открывая карточки товаров по одной.

  • Создайте на сервере папку wa-data/public/site/syrattach — например, в файловом менеджере приложения «Сайт»
  • Загрузите в эту папку файлы, которые нужно прикрепить к товарам
  • Добавьте в CSV-файл одну или несколько колонок «Прикреплённый файл»
  • В строке товара укажите в этой колонке имя файла из папки wa-data/public/site/syrattach

Прикрепляемый файл должен лежать строго в указанной папке: URL и вложенные папки не поддерживаются. При импорте ничего не удаляется и не перезаписывается — каждый файл хранится в собственной папке, поэтому одинаковые имена не конфликтуют, а повторный импорт прикрепит к товару ещё одну копию файла. После импорта содержимое папки wa-data/public/site/syrattach можно удалить.

Максимальный размер загружаемых файлов

Ограничение задаётся не плагином, а настройками сервера, на котором работает Магазин. Если файл не загружается, проверьте в php.ini значения переменных upload_max_filesize, post_max_size и memory_limit. Действующее ограничение плагин показывает прямо в области загрузки файлов.

Требования

  • Shop-Script 10.0 или выше
  • Webasyst 3.0 или выше
  • PHP 7.4 или выше

Интерфейс плагина локализован для русского, английского, украинского, белорусского, казахского, немецкого, нидерландского и французского языков.
