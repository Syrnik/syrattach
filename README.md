# Syrattach — Загрузка файлов к товарам

**[English version](README_en.md)**

Плагин для Shop-Script Webasyst, который добавляет функциональность загрузки и управления файлами, прикреплёнными к товарам.

## Возможности

- ✅ Загрузка файлов к товарам в администраторской панели (новый и старый редакторы)
- ✅ Поддержка drag-and-drop для удобной загрузки
- ✅ Загрузка файлов через выбор в диалоге
- ✅ Визуальный прогресс-бар при загрузке
- ✅ Управление списком загруженных файлов
- ✅ Отображение файлов на фронтенде магазина
- ✅ Совместимость с Premium версией Webasyst
- ✅ Кастомизируемые шаблоны отображения

## Требования

- Webasyst Framework 2.x
- Shop-Script 12.x или выше
- PHP 7.4 и выше

## Установка

1. Скачайте плагин со страницы [Webasyst Marketplace](https://www.webasyst.ru/store/plugin/shop/syrattach/)
2. В администраторской панели перейдите в **Магазин → Плагины**
3. Нажмите кнопку загрузки и выберите архив плагина
4. Активируйте плагин

## Использование

### Администраторская панель

1. Откройте редактор товара
2. В разделе **Файлы** выберите файлы для загрузки:
   - Перетащите файлы (drag-and-drop)
   - Или нажмите на поле для выбора файлов
3. Дождитесь завершения загрузки
4. Файлы автоматически добавятся в список товара
5. Сохраните товар

### Фронтенд магазина

Загруженные файлы отображаются на странице товара согласно выбранному шаблону оформления.
